## 1. Описание предметной области "Система бронирования гостиницы"

Предметная область: бронирование размещения.

Основные пользователи:

- постояльцы отеля;
- служба приёма и размещения;
- сотрудники отеля.

Основные процессы:

- ведение информации о гостиницах и номерах;
- поиск доступных номеров;
- создание бронирования;
- размещение гостей и оплата.

Основные задачи информационной системы:

- ведение актуального статуса номеров;
- управление тарифными планами;
- управление бронированием через сайт;
- формирование отчётов.

## 2. Объекты данных

Объект 1

Название:

Номер.

Назначение:

Учёт колличество проживающих лиц и их состояния.

Какая информация должна храниться:

Номер комнаты, тип, вместимость, этаж, статус (свободен/занят).


Объект 2

Название:

Бронь.

Назначение:

Фиксация заказа на проживание.

Какая информация должна храниться:

Номер брони, дата заезда/выезда, ФИО гостя, тип номера, статус заселения, сумма оплаты, комментарии гостя.

Объект 3

Название:

Постоялец.

Назначение:

Хранение информации о госте.

Какая информация должна храниться:

ФИО гостя, предоставляющего документы; наличие карты лояльности, запрет на посещение.

5. Статус.

Атрибуты:

2. Дата заезда.

4. Желаемый тип.
   Тип данных: строковые.

Атрибуты:

1. ФИО гостя, предоставляющего документы.
   Тип данных: строковые.
   Описание: содержит имя, фамилию и отчество гостя, на которого оформлен номер.

2. Наличие карты лояльности.
   Тип данных: логические.
   Описание: хранит иинформацию о наличие/отсутствие карты лояльности.

3. Запрет на посещение.
   Тип данных: логические.
   Описание: хранит иинформацию о наличие/отсутствие оформителя в чёрном списке компании.

## 5. Связи между объектами

Связь 1

Постоялец:
Человек, на которого оформлено размещение.

Бронь:
Заказ на определённый номер (номера).

Тип связи:
1:1

Описание:
На человека оформляется одна бронь, которая может включать в себя даже несколько номеров. Если помещение снимет семья или компания, то связь всё ещё остаётся прежней, поскольку оформитель только один.

Связь 2

Бронь:
Заказ на определённый номер (номера).

Номер:
Квартира или комната, которую снимает постоялец на короткий срок.

Тип связи:
1:N (1:1)

Описание:
Постоялец может снять как 1 номер, так и несколько за раз.
