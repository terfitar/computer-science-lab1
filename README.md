## 1. Описание системы

Название: Google Drive

Ссылка: https://drive.google.com/drive/my-drive?hl=ru

Назначение: Google Drive - облачный сервис для хранения файлов.

Целевая аудитория:
- Предприниматели.
- Школьники.
- Студенты.
- И в целом пользователи сети Интернет, нуждающиеся в хранении файлов и удалённом доступе к ним.

Основные возможности:
- Хранение файлов.
- Создание папок.
- Экспорт файлов на устройство.
- Импорт файлов с устройства.
- Удаление файлов из облачного хранилища.
- Создание файлов в приложениях Google.

Выбранный сценарий:
Добавление файла в хранилище.

В рамках сценария пользователь открывает окно создания файла, выбирает загрузку файла, выбирает нужный на устройстве, добавляет его в хранилище и проверяет реззультат.

## 5. Описание пользовательского сценария

### 5.1. Выбранный сценарий

Название сценария: загрузка файла в облочное хранилище Google Drive.

Цель сценария: добавить новый файл в хранилище.

### 5.2. Последовательность выполнения сценария

Этап 1. Пользователь открывает страницу

Пользователь авторизуется в Google Drive, нажимает кнопку "Создать".

На этом этапе браузер загружает необходимые HTML-, CSS- и JavaScript-ресурсы.

Этап 2. Пользователь открывает список типов файлов

Пользователь нажимает на нужный тип.

JavaScript обрабатывает действие пользователя и открывает интерфейс библиотеки блоков.

Этап 3. Пользователь выбирает файл

Пользователь выбирает нужный файл на устройстве.

Клиентская часть определяет выбранный пользователем файл и подготавливает данные для его добавления.

Этап 4. Клиентская часть взаимодействует с сервером

При необходимости браузер отправляет запрос на сервер через API.

Этап 5. Сервер обрабатывает запрос

Сервер принимает запрос и выполняет необходимые операции.

Предположительно, сервер проверяет доступ пользователя к проекту и обрабатывает данные страницы.

Если требуется сохранение изменений, данные записываются в соответствующее хранилище.

Этап 6. Сервер возвращает результат

После обработки сервер возвращает результат клиентской части.

Клиент получает необходимые данные и продолжает работу на странице.

Этап 7. Интерфейс отображает результат

JavaScript обрабатывает полученный результат и обновляет интерфейс.

Новый файл появляется в облаке.

Пользователь видит результат своего действия.

Была построена упрощенная архитектурная схема информационной системы Google Drive.

1. Пользователь выполняет действия в интерфейсе Google Drive.
