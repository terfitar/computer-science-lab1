# computer-science-lab1
Лабораторная работа №1

## 1. Описание системы

Название: Google Drive

Ссылка: https://drive.google.com/drive/my-drive?hl=ru

Назначение: Google Drive - облачный сервис для хранения файлов.

Целевая аудитория:
- Предприниматели.
- Школьники.
- Студенты.
- И в целом пользователи сети Интернет, нуждающиеся в хранении файлов и удалённом доступе к ним.

Основные возможности:
- Хранение файлов.
- Создание папок.
- Экспорт файлов на устройство.
- Импорт файлов с устройства.
- Удаление файлов из облачного хранилища.
- Создание файлов в приложениях Google.

Выбранный сценарий:
Добавление файла в хранилище.

В рамках сценария пользователь открывает окно создания файла, выбирает загрузку файла, выбирает нужный на устройстве, добавляет его в хранилище и проверяет реззультат.

## 2. Анализ пользовательского интерфейса

### 2.1. Основные страницы и разделы

В рамках лабороторной работы исследуется информационная система Google Drive - облачное хранилище.

В системе используются следующие основные страницы и разделы:

- Страница автаризации.
- Личный кабинет пользователя.
- Список выгруженных файлов.
- Список файлов в корзине.
- Спам.
- Строка поиска файлов.
- Настройки интерфейса.

### 2.2. Ключевые элементы интерфейса

| Элементы интерфейса           | Назначение                                      |
|-------------------------------|-------------------------------------------------|
| "Google Workspace"            | Открыват страницу предрегистрафции              |
| Главное меню                  | Навигации между основными разделами             |
| Личный кабинет                | Управление аккаунтом                            |
| Кнопка создания               | Создание и добавление файлов                    |
| "Мой диск"                    | Показывает файлы из хранилища                   |
| "Компьютеры"                  | Отображает синхронизированные компьютеры        |
| "Доступные мне"               | Последние использованные файлы                  |
| "Недавние"                    | Более подробная версия предыдущей страницы      |
| "Помеченные"                  | Файлы отмеченные пользователем                  |
| "Спам"                        | Файлы спам-рассылки                             |
| "Корзина"                     | Файлы, добавленные сюда, удалятся через месяц   |
| "Хранилище"                   | Показывает заполненность и содержание хранилища |

### 2.3. Выполнение пользовательского сценария

Выбранный сценарий: загрузка файла в облочное хранилище.

Последовательность действий:

1. Открыть сайт Google Drive.
2. Выполнить авторизацию в личном кабинете.
3. Нажать на кнопку "Создать".
4. Выбрать загрузку файла.
5. Выбрать файл.
6. Открыть файл.
7. Проверить,что файл выгрузился.

В результате выполнения сценария в хранилище был добавлен файл.

### 2.4. Компоненты участвующие в сценарии

| Компонент интерфейса        | Назначение                                    | Этап сценария |
|-----------------------------|-----------------------------------------------|---------------|
| Форма авторизации           | Позволяет пользователю войти в личный кабинет | 2             |
| Личный кабинет              | Предоставляет доступ к файлам в хранилище     | 2-3           |
| Кнопка создания             | Открывает список создания и загрузки          | 3             |
| Список создания и загрузки  | Даёт выбрать как добавить файл                | 4             |
| Список файлов на устройстве | Позволяет найти нужный файл                   | 5             |
| Кнопка открытия файла       | Добавляет файл в хранилище                    | 6             |
| Кнопка "Недавние"           | Позволяет увидель последние выгруженые файлы  | 7             |
