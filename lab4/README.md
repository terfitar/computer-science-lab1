# Лабораторная работа №4

**Тема:** Анализ учебного набора данных с помощью SQL.

**Предметная область:** система образовательной платформы.

**Цель работы:** научиться анализировать данные из нескольких связанных таблиц с помощью SQL, применять фильтрацию, сортировку, агрегирование, группировку и объединение таблиц, проверять целостность данных и формулировать аналитические выводы.

## Описание предметной области

Рассматривается сервис образовательной платформы. В системе хранятся сведения об учебных группах, студентах, преподавателях, курсах, записях на курсы и итоговых оценках.

Учебная база данных SQLite содержит шесть связанных таблиц:

| Таблица | Назначение | Основные поля | Количество записей |
|---|---|---|---:|
| `groups` | Учебные группы | id, group_name, study_year | 12 |
| `students` | Студенты | id, full_name, group_id, admission_year | 240 |
| `teachers` | Преподаватели | id, full_name, department | 15 |
| `courses` | Курсы | id, course_name, hours, teacher_id | 30 |
| `enrollments` | Записи студентов на курсы | id, student_id, course_id, enrolled_at, status | 1000 |
| `results` | Итоговые оценки завершённых записей | id, enrollment_id, score, completed_at | 850 |
| **Итого** | | **2 147** |

Таблицы связаны между собой с помощью первичных и внешних ключей. Это позволяет анализировать результаты в разрезе студентов, групп и преподавателей, разрабатывать учебный план и исследовать сведения о курсах.

Для выполнения SQL-запросов используется онлайн-среда SandboxSQL.

## Выполненная работа

В ходе лабораторной работы:

1. Загружена база данных SQLite, проверено наличие шести таблиц и количество записей в каждой из них.
2. Изучены структура таблиц, их поля, первичные и внешние ключи. Сформулированы аналитические вопросы.
3. Выполнена фильтрация и сортировка данных с помощью `WHERE`, `ORDER BY` и `LIMIT`.
4. Рассчитаны агрегированные показатели с использованием `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`. Выполнены группировка с `GROUP BY` и фильтрация групп с `HAVING`.
5. Исследованы связи между таблицами с помощью `INNER JOIN` и `LEFT JOIN`.
6. Выполнены проверки корректности данных и ссылочной целостности.
7. Проведено самостоятельное аналитическое исследование деятельности сервиса, включая анализ аренд и выручки, сформулированы выводы на основе результатов SQL-запросов.

## Результат

Подготовлен аналитический отчёт, содержащий описание структуры базы данных, аналитические вопросы, SQL-запросы, таблицы результатов, скриншоты их выполнения в SandboxSQL и выводы по каждому этапу.

По результатам анализа исследованы активность студентов, успешность прохождения курсов и корректность хранящихся данных.
